# Aster Study Planner

Aster is a browser-based study planner served by a small Express server.

## Requirements

- Node.js 18 or later
- npm

## Run locally

```sh
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

The server uses port `3000` by default. Set the `PORT` environment variable to use a different port, for example:

```sh
PORT=8080 npm start
```

On Windows Command Prompt, use `set PORT=8080 && npm start` instead.
